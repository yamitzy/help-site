# Помочь Темирлану — сайт благотворительного сбора

Статический сайт (HTML5 / CSS3 / Vanilla JS, без библиотек и фреймворков),
готовый к публикации на GitHub Pages. Содержит реальные медицинские
документы и реквизиты семьи Темирлана Альбекова.

Сайт написан от лица семьи — весь видимый текст уже готов к публикации,
служебных пометок на страницах нет. Все настраиваемые данные (реквизиты,
контакты, суммы) вынесены в начало `script.js`.

## Если локальное видео всё ещё не показывается

Самые частые причины:
1. **Не то имя файла или папка.** Код ищет ровно
   `assets/videos/message.mp4` (с учётом регистра). Проверьте, что файл
   называется и лежит именно так.
2. **Слишком большой файл.** При загрузке через веб-интерфейс GitHub
   файлы больше ~25 МБ иногда загружаются не полностью. Если видео
   тяжёлое — сначала сожмите его (например, через HandBrake или
   онлайн-компрессор) до 10–20 МБ.
3. **Формат кодека.** Видео с айфона иногда сохраняется в HEVC/H.265 —
   его не все браузеры умеют проигрывать. Если проблема не в имени файла
   и не в размере — попробуйте пересохранить видео в формате H.264 (MP4).
4. Пока проблема не решена, ссылка «Смотреть в Instagram» под видео
   работает в любом случае — так что переходы по ссылке никогда не
   потеряются.

robots.txt, sitemap.xml
assets/
  images/               — фото; замените файлы напрямую (см. ниже), код трогать не нужно
  icons/favicon.svg
  documents/
    vypiska-2019.pdf      — выписка, первая операция (настоящая)
    vypiska-2021.pdf       — выписка, вторая операция (настоящая)
    vypiska-2024.pdf        — эпикриз, третья операция (настоящая)

    thumb-*.jpg                  — миниатюры для карточек документов

## Как добавить настоящие фотографии

В `assets/images/` уже лежат файлы с нужными именами — просто замените
их содержимое, оставив то же имя и расширение `.jpg`:
- `hero-photo.jpg` — большое фото на первом экране
- `story-1.jpg`, `story-2.jpg` — фото в разделе «История»
- `video-poster.jpg` — обложка видео до нажатия play
- `og-cover.jpg` — превью для соцсетей при пересылке ссылки

Редактировать `index.html` не нужно — картинки просто заменяются файлом
с тем же именем.

## Как поменять суммы, реквизиты и контакты

Суммы — в `script.js`, в самом начале:

```js
const CAMPAIGN = {
  goalRub: 1560000,       // цель на четвёртую операцию (без перелёта и проживания), ₽
  raisedKzt: 358000,      // сколько уже собрано, ₸
  exchangeKztPerRub: 6.0, // приблизительный курс ₸ за 1 ₽ — обновите при необходимости
};
```

Меняете эти три числа — пересчитываются все цифры на сайте: прогресс-бары,
кольца, счётчики, мобильная панель.

Когда станут известны стоимость перелёта и проживания, добавьте их к
`goalRub` и обновите карточку расходов «Перелёт и проживание после
выписки» в `index.html` (сейчас там указано «Уточняется»).

Реквизиты для пожертвований — прямо в `index.html`, раздел «Как помочь»
(`id="donate"`): номера карт и телефонов в блоках `req-value`, значения
для копирования — в атрибутах `data-copy` на кнопках рядом.

Контакты — в `REAL_CONTACTS` в `script.js`, как описано выше.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория (замените
   старые файлы новыми — см. ваш предыдущий вопрос в переписке, если
   нужно напомнить порядок действий).
2. Settings → Pages → Source: Deploy from a branch → `main`, папка
   `/ (root)`.
3. Через пару минут сайт обновится. Если видите старую версию — обновите
   страницу с Ctrl+F5 / Cmd+Shift+R, чтобы сбросить кэш браузера.
4. Обновите `canonical` и Open Graph URL в `index.html`, а также
   `robots.txt` и `sitemap.xml`, указав реальный адрес сайта вместо
   `example.org`.

## Честность и этика

Сайт открыто показывает, что позади уже три операции и что предстоящая
— не последняя. Пожалуйста, не убирайте эти формулировки: сайт устроен
так, чтобы вызывать доверие именно за счёт честности, а не приукрашивания.
